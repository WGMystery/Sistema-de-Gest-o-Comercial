# Sistema de Gestão Comercial

## Sobre o projeto
Sistema web desenvolvido para auxiliar pequenos empreendimentos comerciais na organização de produtos, vendas e controle de estoque.

## Problema identificado
Pequenos empreendimentos enfrentam dificuldades para organizar vendas, estoque e pedidos devido ao uso de registros manuais. Isso provoca perda de tempo, dificuldade para localizar informações e possibilidade de erros.

## Público-alvo
- Proprietários de pequenos empreendimentos.
- Funcionários responsáveis por vendas e estoque.
- Clientes e comunidade beneficiados por um atendimento mais organizado.

## Objetivo
Desenvolver uma aplicação web simples, responsiva e intuitiva para centralizar informações comerciais.

## Funcionalidades
- Cadastro de produtos.
- Consulta e edição de produtos.
- Registro de vendas.
- Controle de estoque.
- Alertas de estoque baixo.
- Consulta de informações comerciais.

## Tecnologias
- Python 3.12
- Flask 3.x
- HTML5
- CSS3
- SQLite

## Arquitetura
Arquitetura monolítica em camadas baseada no padrão MVC:
- Model: gerenciamento dos dados.
- View: interface do usuário.
- Controller: processamento das ações.

## Banco de dados
SQLite será utilizado para armazenar produtos, vendas e informações de estoque.

## Telas do protótipo
1. Menu inicial.
2. Cadastro de produtos.
3. Listagem e alertas de estoque.

## Validação
O protótipo será avaliado por meio de três tarefas:
1. Localizar a funcionalidade de cadastro.
2. Cadastrar um produto fictício.
3. Identificar um alerta de estoque baixo.

## Critérios de aceitação
- Conclusão das três tarefas sem ajuda.
- Cadastro em até 180 segundos.
- Satisfação mínima de 4 em uma escala de 1 a 5.
