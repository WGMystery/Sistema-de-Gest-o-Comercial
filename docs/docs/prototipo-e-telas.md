# Protótipo e Descrição das Telas

## Tela 1 - Menu inicial

Apresenta a entrada principal do sistema Gestão Comercial, utilizada pelo proprietário e funcionários para acessar as funções de produtos, vendas, estoque e relatórios.

Os botões Cadastrar Produto, Registrar Venda e Ver Relatórios direcionam às principais funcionalidades. A tela também apresenta indicadores de produtos cadastrados, vendas realizadas e estoque disponível.

A interface possui textos claros, ícones intuitivos, bom contraste, botões destacados e navegação organizada.

## Tela 2 - Cadastro de produtos

Permite cadastrar produtos no sistema, substituindo os registros manuais.

O formulário contém:
- Nome do produto.
- Categoria.
- Preço.
- Quantidade em estoque.
- Descrição opcional.

O botão Salvar Produto confirma o cadastro, enquanto Cancelar interrompe a operação.
O sistema deverá validar os campos obrigatórios, impedir valores negativos e apresentar mensagens de erro claras.
## Tela 3 - Listagem e alertas
Apresenta a lista de produtos cadastrados, preços, quantidades e disponibilidade no estoque.
Possui campo de busca, filtros e opções para editar ou excluir registros.
Os alertas identificam produtos disponíveis, com estoque baixo ou sem estoque.
As informações são apresentadas por cores, textos e símbolos para facilitar a compreensão e garantir acessibilidade.
